# 汉字小探险家

给孩子玩的中文认字挑战游戏。1446 个汉字、28 个主题、372 个关卡；每关 4 个字，先听读，再进行听音选字、看图认字或补全词语挑战。

## 开始游戏

在线版： https://yjw94ss.github.io/hanzi-adventure/

本地版：下载仓库 ZIP，解压后打开 `index.html` 即可。也可在目录运行 `python3 -m http.server 8000`，访问 `http://localhost:8000`。

## 玩法

- 地图：从基础字出发，也可以自由选关。
- 汉字图鉴：按主题浏览，搜索汉字、例词或带声调的拼音，点击字卡听音、单独学字。
- 每次认识 4 个字，每轮挑战 8 题，不计时、不扣生命。
- 选错可以再试，用过提示或选错后的答对记作“练习后答对”。
- 错字优先复习；最近连续独立答对两次的字卡呈绿色。
- 每完成一个新关卡收集一张贴纸。
- 家长入口：简单算术门槛、开启拼音、调整 3/4 个选项、查看记录、导入导出记录。

基础 24 字配有原创 SVG 插画，其余字结合例词、语音与词语填空学习。字库按生活主题组织，包含较难的字，由家长按孩子兴趣和能力选学。多音字按展示例词中的读音练习；不涵盖该字所有读音。拼音由 pypinyin 结合例词生成，并对部分多音字作了检查。

## 声音

全部语音已预生成并随仓库提供，采用 Microsoft edge-tts 的 `zh-CN-XiaoyiNeural`，经 FFmpeg 标准化至目标 -17 LUFS、真峰上限 -2 dBTP。播放语速为原录音的 0.8 倍，保持原音调，让孩子更容易听清。游戏运行不调用浏览器系统朗读，不需要语音 API 密钥。在线使用时按需加载语音；离线使用请完整下载 audio 目录。

## 进度与隐私

无广告、无账号、无后端、无分析埋点。练习记录保存于当前浏览器 localStorage；不同设备、不同浏览器、不同网址的记录彼此独立。家长页可导出 JSON 备份，并在其他设备导入；导入会替换当前设备的练习记录。清理浏览器数据会删除记录。家长入口的算术题用于减少孩子误入，不是安全认证。

## 文件

- `index.html` / `style.css`：入口与响应式界面。
- `data.js`：汉字、拼音、例词、主题、关卡。
- `art.js`：本地 SVG 插画和图标。
- `core.js`：答题、提示和复习状态。
- `app.js`：页面、语音、图鉴、家长页、本地保存。
- `audio/`：逐字语音和反馈音频。
- `tests/`：核心行为、字库完整性测试。

原生 HTML/CSS/JavaScript，无运行时第三方依赖，无需安装 npm 包。

测试：`node --test tests/*.cjs`

GitHub Pages：仓库 Settings → Pages，选择 `main` 分支和 `/ (root)`。`.nojekyll` 关闭 Jekyll 处理。
